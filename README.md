# 可直接替換版本 v6

將本資料夾中的檔案上傳到 GitHub Repository 根目錄，覆蓋同名檔案：

- index.html
- app.js
- style.css
- sw.js
- manifest.webmanifest
- vocabulary_template.csv
- icons/

此版本會：

1. 顯示明確的載入與錯誤狀態。
2. 支援 iPhone 手動匯入 CSV。
3. 啟動時自動讀取同一個 GitHub Pages 目錄的 vocabulary_template.csv。
4. 保留既有 Pass/Fail 紀錄。
5. 使用 v6 快取名稱，避免沿用舊程式。
