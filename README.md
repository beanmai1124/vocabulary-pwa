# Vocabulary PWA v10

## 規則
- 今天已複習過的單字，今天不再出現。
- Fail：隔天再次複習，不會在同一天重複。
- Pass：1、3、7、14、30、60、120 天。
- Overdue：到期日早於今天且今天尚未複習，優先顯示，不自動增加 Fail。
- 卡片隨機顯示英文或中文。
- 不顯示上一個、下一個、隨機按鈕。
- 「查看全部單字」為唯讀。
- 「Failed 待複習」顯示最後一次作答為 Fail 且已到期的項目。

## Excel
工作表：Vocabulary。必填欄位：ID、English、Chinese。可選欄位：example、example_zh、category。
